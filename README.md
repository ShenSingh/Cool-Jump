# 🥷 Cool Jump - Ninja Platformer Game

**Cool Jump** is a fun 2D platformer game built with **Godot Engine**, where you control a ninja who collects cherries and racks up points!

## 🎮 Gameplay Features

- 🥷 Play as a fast and agile ninja
- 🍒 Collect cherries to earn points
- 🧱 Jump across platforms and avoid falling
- 🧾 Real-time point counter on screen

## 📦 Built With

- **Godot Engine** (v4.x)
- GDScript

## 🕹️ How to Play

- Use arrow keys or `A/D` to move left/right
- Press `Space` or `W` to jump
- Collect all the cherries to score points
